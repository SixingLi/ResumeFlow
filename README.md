# ResumeFlow V1

这是一个纯前端、无服务器的简历排版工具，适合 GitHub Pages + iPad Safari。

## 部署

1. 在 GitHub 新建公开仓库：`ResumeFlow`
2. 上传本目录中的 5 个文件。
3. GitHub → Settings → Pages
4. Source 选择 `Deploy from a branch`
5. Branch 选择 `main` / `/ (root)` → Save
6. 等待部署完成。

目标网址：

`https://sixinglilsx-cmd.github.io/ResumeFlow/`

## iPad

Safari 打开网址 → 分享 → 添加到主屏幕。

## 注意

V1 的 PDF 导出使用浏览器打印功能。iPad 上选择“打印”后可进入系统分享/保存流程。
